# Tic-tac-toe game using python
## project overview
tic tac toe is a simple two player game developed using python. The game is played on a 3*3 board using X and O.
Players take turns selecting positions on the board. The program checks the player's input, updates the board, and checks whether a player has won the game has ended in a draw.

## How to Play
1. The game displays a 3*3 board.
2. player x starts the game.
3. enter a position from 1 to 9.
4. player o gets the next turn.
5. the game continues until a player wins or the board is full.
6. if three same symbols are in a row, column or diagonal, the player wins.
7. if all positions are filled without a winner, the game is a draw.
